High — Адаптивный лендинг (Gulp + GitLab CI/CD)

Основные возможности
Автоматическая сборка: Gulp обрабатывает SCSS, JavaScript, изображения и шрифты.
Оптимизация медиа: Автоматическое сжатие изображений (jpg, png, svg) без потери качества.
Адаптивность: Готовая структура для создания отзывчивого дизайна (используются медиазапросы или адаптивные изображения).
Современный JavaScript: Транспиляция через Babel для поддержки старых браузеров.
Автоматический деплой: CI/CD пайплайн в GitLab, который при пуше в ветку main:

- Собирает проект.
- Публикует его на GitLab Pages.
- Деплоит на внешний сервер по SSH.

Технологии:

- Gulp 5 — таск-менеджер для сборки.
- Sass (SCSS) — препроцессор для стилей.
- Babel — транспилятор JavaScript.
- PostCSS / Autoprefixer — добавление вендорных префиксов.
- CSSnano / CleanCSS — минификация CSS.
- Terser / Uglify — минификация JavaScript.
- gulp-image / gulp-imagemin — оптимизация изображений.
- BrowserSync — горячая перезагрузка для разработки.

Как запустить локально

1. Клонируйте репозиторий: https://github.com/paveltomilov/high.git
2. Установите зависимости

```bash
npm install
```

3. Запустите режим разработки

```bash
npm run gulp
```

Эта команда:

- Соберет проект в папку dist.
- Запустит сервер BrowserSync с горячей перезагрузкой.
- Будет отслеживать изменения в src/ и автоматически пересобирать проект.

4. Соберите проект для продакшена

```bash
npm run build
```
