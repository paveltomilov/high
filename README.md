# HIGH PASS

Адаптивная вёрстка сайта с использованием Desktop First подхода, CSS Grid и Flexbox.

## Технологии

- HTML5
- SCSS (Sass)
- Gulp (сборка)
- БЭМ (именование классов)
- Адаптивная вёрстка (Desktop First)
- CSS Grid
- Flexbox

## Установка и запуск

```bash
# Установка зависимостей
npm install
```

## Запуск сборки Gulp

```bash
gulp
```
